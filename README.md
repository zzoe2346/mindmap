# mindmap

생각을 가지로 펼치고 서로 연결하는 개인용 Mac 앱입니다. 로그인이나 구독 없이 문서를 Mac에 저장합니다.
프로젝트 이름은 임시로 mindmap을 사용합니다.

## 시작하기

`dist/mindmap.app`을 더블 클릭합니다. 원하는 위치로 앱을 복사해 사용해도 됩니다.
홈에서 새 마인드맵을 만들거나 최근 문서를 엽니다.
선택한 중심 토픽에 바로 이름을 입력하고, Tab으로 하위 토픽을 추가하세요.
⌘S로 이름과 위치를 정하면 이후 입력 중 내용도 자동 저장됩니다.

- 하위 토픽과 형제 토픽을 키보드로 추가합니다.
- 긴 한글 설명과 여러 줄 텍스트를 입력합니다.
- 드래그로 형제 순서를 바꾸거나 다른 토픽 아래로 이동합니다.
- 여러 가지를 함께 선택하고 복사, 붙여넣기, 복제합니다.
- 홈에서 문서 미리보기, 즐겨찾기와 내용 검색을 사용합니다.
- 관계선에 설명과 화살표를 넣고 곡선을 조절합니다.
- 오른쪽/양쪽 배치, 확대, 화면 이동, 글자 크기와 테마를 조절합니다.
- 삭제와 편집을 ⌘Z로 되돌립니다.

`.mindmap` 파일을 사용합니다. XMind 파일 가져오기는 포함하지 않습니다.
