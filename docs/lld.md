# 구조와 저장 계약

- MindmapCore: 버전이 있는 Codable 값 모델, 트리 변경과 무결성 검증, 자동 배치.
- MindmapApp: NSDocument 문서 수명과 저장, 메인 액터 편집 세션, AppKit 캔버스, SwiftUI 속성 패널.
- JSON 문서에 토픽 UUID/부모 UUID/순서/가지 방향/접힘, 관계 UUID/양끝/설명/화살표/곡률을 저장한다.
- formatVersion=1. 단일 루트, 유일 ID, 부모 존재, 모든 노드 연결, 순환 금지, 관계 양끝 존재를 로드 시 검증한다.
- 문서 변경마다 NSUndoManager에 이전 값 스냅샷을 등록한다. 드래그와 제목 편집은 완료 시 한 번 반영한다.
- NSDocument의 autosavesInPlace와 autosavesDrafts를 사용한다. 저장 위치를 정하기 전 초안도 시스템 복구에 참여한다.
- 저장은 NSDocument의 안전한 쓰기 경로에 맡긴다. 읽기 실패는 사용자 오류로 표시하며 기존 문서를 교체하지 않는다.
- 선택과 줌/팬은 창 상태, 토픽 글자 크기와 테마는 앱 설정이다. 캔버스 배치는 토픽 트리에서 계산한다.

## 편집과 보관함 확장

BranchEditing은 선택한 하위 항목을 정규화해 최상위 가지들만 이동한다. 배열의 형제 순서와 UUID를 보존하고 관계선은 변경하지 않는다.
클립보드는 합성 루트를 가진 검증 가능한 MindMap JSON을 사용한다. 붙여넣기는 모든 ID를 새로 만들고 선택 내부 관계선만 복제한다.
드롭 판정은 캔버스 좌표의 중앙/위/아래 영역을 해석해 parent, before, side를 반환하며 자동 검사와 실제 드래그가 같은 함수를 사용한다.

입력 중 세션의 확정 모델을 덮어쓰지 않는다. mapForSaving은 편집 버퍼를 합친 스냅샷으로 레이아웃과 NSDocument 저장에 사용한다.
입력 변경 시 문서를 dirty로 표시해 자동 저장을 예약한다. 확정 시 기존 모델에서 새 제목으로 하나의 undo를 등록한다.
취소 시 원래 모델을 다시 저장하도록 dirty 상태를 갱신한다. 앱 강제 종료 복구 자체는 NSDocument의 초안 복구에 맡긴다.

LibraryStore는 최근 문서 URL과 자체 경로 기록, 현재 열린 초안을 병합한다. 파일을 스캔하거나 사용자 문서를 이동하지 않는다.
홈 즐겨찾기와 문서별 viewport는 앱 UserDefaults에 보관한다. 미리보기는 저장된 맵 구조로 그린다.
이름 변경은 NSDocument 표준 UI로 수행하며, 경로가 실제 이동되면 즐겨찾기와 viewport도 새 경로로 이전한다.
문서 복제는 현재 편집 내용을 가진 새 미저장 문서를 만들며 원본 파일은 유지한다.
