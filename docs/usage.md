# 사용법

## 토픽

토픽을 클릭해 선택합니다. Tab은 하위 토픽, Enter는 형제 토픽을 추가합니다.
중심 토픽에서 Enter를 누르면 하위 토픽을 만듭니다.
더블 클릭, Space, ⌘Enter 또는 속성 패널의 제목 편집으로 편집합니다.
편집 중 Enter는 완료, Shift-Enter는 줄바꿈, Esc는 취소입니다. 붙여넣은 줄바꿈은 보존합니다.
편집 중 Tab은 제목을 확정하고 하위 토픽을 만듭니다.

Delete는 선택한 토픽과 그 하위 가지를 삭제합니다. 관련 관계선도 함께 삭제하며 ⌘Z로 복구할 수 있습니다.
중심 토픽은 삭제하지 않습니다. 방향키는 가까운 토픽으로 선택을 이동합니다.

## 가지와 화면

⌘/ 또는 토픽 끝의 +/− 버튼으로 접거나 펼칩니다.
토픽을 다른 토픽 위로 드래그하면 목적지가 초록색으로 표시됩니다. 그 위에 놓으면 부모가 바뀝니다.
자기 자신이나 자기 하위 가지로는 이동할 수 없습니다.

빈 공간 드래그와 트랙패드 스크롤로 화면을 이동합니다. 핀치 또는 ⌘+/⌘−는 확대와 축소,
⌘0은 전체 보기, ⌘1은 실제 크기입니다. 속성 패널에서 오른쪽/양쪽 배치를 선택합니다.
⌥⌘I는 속성 패널을 접거나 펼칩니다.

## 관계선

출발 토픽을 선택하고 ⇧⌘R 또는 툴바의 관계선을 누릅니다.
대상 토픽을 클릭하거나 방향키로 선택한 뒤 Enter를 누르면 연결됩니다. Esc는 연결 취소입니다.
같은 두 토픽을 다시 연결하면 기존 관계선을 선택합니다.

관계선을 클릭하거나 속성 패널의 관계선 목록에서 선택합니다.
설명, 화살표 방향과 곡률을 변경할 수 있습니다. 선택된 선의 파란 점을 드래그해 곡률을 조절할 수도 있습니다.
관계선 경로는 주변 토픽을 자동으로 우회하지 않으므로 겹치면 곡률을 조절하세요.
접힌 가지 아래의 관계선은 화면에서만 숨겨지며 문서에 유지됩니다.

## 파일과 복구

⌘N 새 문서, ⌘O 열기, ⌘S 저장, ⇧⌘S 다른 이름으로 저장입니다.
완료한 편집은 NSDocument의 자동 저장 대상입니다. 입력 중 제목은 Enter로 확정하거나 편집기 밖으로 이동하세요.
최초 파일 위치를 정하기 전에는 macOS의 임시 문서 저장을 사용합니다. 종료 시 저장 대화상자가 나오면 위치를 지정합니다.
이름을 지정해 저장하는 것이 문서를 다시 찾는 가장 확실한 방법입니다.

손상된 파일이나 지원하지 않는 버전을 읽으면 오류를 표시하고 원본을 변경하지 않습니다.
설정은 앱에만 적용되며 테마와 글자 크기는 다음 실행에도 유지됩니다.
