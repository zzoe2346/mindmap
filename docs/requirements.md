# 제품 요구사항

2026-10-12 사용자 승인: Mac 독립 앱, 임시 이름 mindmap. 꼬꼬무와 배우자의 개발 지침을 참고한다.

첫 버전은 중심/하위/형제 토픽 추가와 삭제, 제목 편집, Tab 하위 추가, Enter 형제 추가,
가지 접기와 펼치기, 드래그 부모 변경, 확대와 화면 이동, 관계선 추가와 삭제,
관계선 설명/방향/곡률 조절, 로컬 파일 열기/저장, 자동 저장과 실행 취소/다시 실행을 제공한다.

추가 편의: 방향키 탐색, 전체 보기, 속성 패널 숨기기, 밝게/어둡게/시스템 테마, 글자 크기 조절.
최소 OS는 참고 앱처럼 macOS 26이다. 런타임 외부 의존성은 없다.

마지막 사용자 지시로 XMind 가져오기는 제외했다. 계정, AI, 클라우드, 협업, 구독 기능은 없다.
새 문서는 중심 토픽 하나에서 시작한다. 예시 파일은 QA용이며 사용자 데이터가 아니다.
삭제와 부모 변경은 취소 가능하다. 루트 삭제와 순환 부모 관계는 허용하지 않는다.
접힌 토픽 아래의 관계선은 잠시 숨기되 데이터를 삭제하지 않는다.
저장되지 않은 문서와 종료 동작은 NSDocument의 표준 저장/복구 체계를 따른다.

## 2026-10-12 편집 UX와 홈 확장

사용자가 제안한 순서의 전체 구현을 승인했다.
- 드래그로 형제 순서 변경, 다른 부모로 이동, 삽입 위치와 이동 미리보기, Esc 취소.
- Command/Shift 클릭 다중 선택, 선택한 여러 가지 이동, 가지 복사/붙여넣기/복제.
- 선택 상태에서 바로 입력, 입력 중 토픽 크기와 트리 재배치, 편집 전후 글꼴 유지, 토픽 너비 조절.
- 입력 버퍼를 자동 저장 스냅샷에 포함하고, 제목 편집은 확정 시 한 번의 문서 실행 취소로 관리.
- 홈의 최근 문서 카드, 열린 초안, 즐겨찾기, 제목과 토픽 내용 검색, 열기/이름 변경/복제/Finder 보기.
- 문서별 확대율과 화면 위치 복원. 편집 화면에서 토픽 검색 시 접힌 상위 가지를 펼침.
- 기존 문서 형식 v1에 선택적 textWidth 필드를 추가해 이전 파일과 호환.
