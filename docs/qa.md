# QA 기록

## 2026-10-12 / 0.1.0

환경: macOS 27.0.1 (26A434), arm64, Swift 6.4, macOS SDK 27.0. 최소 OS 26.0.
소스는 신규 작업 폴더에 작성한 0.1.0 초기 구현이다. 소스 파일 묶음과 바이너리의 SHA-256, 캡처 상태는 assets/screenshots.json을 따른다.

### 자동 검사

- Swift 포맷 strict 검사 통과.
- Core 테스트 9개 통과: 한글/관계선 파일 왕복, 가지 삭제와 관계선 정리, 루트 보존,
  순환 부모 변경 금지, 접힘 보존과 새 하위 추가 시 펼침, 순서와 중복 관계선,
  손상 문서와 미래 버전 거부, 분리된 순환 검출, 다른 크기 61개 토픽의 겹침 없는 배치,
  150단계 깊이 제한.
- App 테스트 3개 통과: NSUndoManager로 삭제한 가지와 관계선 undo/redo, 실패한 읽기에서 기존 문서 보존,
  키보드 관계선 연결과 undo.
- Release 빌드와 codesign --verify --deep --strict 통과.
- 실행 바이너리 LC_BUILD_VERSION: minOS 26.0, SDK 27.0.

### 실제 UI

CUA로 별도 QA 앱과 직접 만든 데이터로 검사했다.
- 한글 제목 붙여넣기, Tab/Enter 하위와 형제 추가, 여러 줄 긴 설명 입력.
- 저장 대화상자로 .mindmap 파일 저장, 파일 열기로 토픽과 제목 복원.
- 관계선 키보드 연결, 설명 편집, 양쪽 화살표와 음수 곡률 설정. 파일에서 값 보존 확인.
- 가지 접기와 undo, 토픽 삭제 시 관계선 정리, undo/redo 복원.
- 긴 설명 입력 완료 후 별도 저장 명령 없이 디스크에 반영된 자동 저장 확인.
- 실제 창과 접근성 목록에서 토픽 이름, 편집기의 텍스트 입력 영역, 속성 명령 확인.

### 발견과 수정

- 편집기가 캔버스의 사용자 정의 접근성 목록에서 누락되어 편집 중 목록에 노출하도록 수정했다.
- 접근성 토픽의 비활성 상태와 잘못된 좌표를 수정해 실제 화면의 토픽 선택을 확인했다.
- 첫 창이 최소 크기로 축소되는 문제를 뷰 초기 크기 명시로 수정했다.
- 저장 패널의 AX setValue만으로는 버튼 상태가 갱신되지 않았다. 실제 입력 후 저장이 정상 동작함을 확인했다.
  문서 형식의 readable/writable type과 확장자도 명시했다.
- 문서 테스트에서 이벤트 루프 없이 undo 자동 그룹을 비활성화해 예외가 발생했다. 테스트에 명시적인 그룹을 추가했다.
- 제목 입력기의 편집 undo를 문서 구조의 undo와 분리했다.

### 미확인과 제한

- CUA 좌표 드래그는 noWindowsAvailable 오류로 완료하지 못했다. 드래그 핸들러는 구현했으며 부모 변경 규칙은 테스트했지만
  실제 포인터로 부모 이동/곡선 핸들 드래그와 트랙패드 핀치 실기 검증은 미완료다.
- 실제 한글 IME 조합, VoiceOver 읽기 순서, 대비 증가/투명도 감소의 시스템 조합은 미확인이다.
- 한글 검증은 실제 앱에 붙여넣은 텍스트를 기준으로 하며 실제 IME 타건과 구분한다.
- macOS 26 실기기와 Intel Mac, 대규모 맵 체감 성능, 비정상 종료 후 미지정 초안 복구는 미확인이다.
- 관계선은 사용자가 곡률을 조정하는 방식이며 장애물 자동 회피는 제공하지 않는다.
- 입력 중인 제목은 확정 전까지 문서 모델에 저장되지 않는다. 확정한 편집에 자동 저장을 적용한다.

### 최종 캡처 제한

마지막 재실행 검증에서 CUA의 네이티브 앱 연결이 timeoutReached로 실패했다.
프로세스 샘플은 메인 스레드가 정상 이벤트 대기 상태임을 보여 주었으며, 이 표본에서 앱의 연산 정체는 관찰되지 않았다.
다만 도구 문제라고 완전히 단정할 수는 없다. 앞선 실제 화면은 도구 결과로 검토했지만 파일로 내보내지 못했고,
최종 바이너리의 테마별 캡처도 완료하지 못했으므로 README에 없는 이미지를 연결하지 않는다.
밝은 기본 화면과 작은 창, 기본 17pt의 실제 표시는 확인했다. 어두운 테마와 최대 28pt 화면은 미확인이다.
