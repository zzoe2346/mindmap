최종 검사: `scripts/check.sh` 포맷 검사, Core 15개와 App 6개 테스트, Release 빌드와 서명 검증 통과.

클립보드 ID 재발급과 내부 관계 복제, 손상 클립보드 원자성, 이전 문서 호환, 입력 버퍼 저장/취소,

### 직접 실행한 검사

별도 식별자의 `work/qa/mindmap UX.app`에서 개인정보 없는 새 문서로 수행했다.
- 홈에서 새 문서 생성, 선택한 중심에 ASCII 타이핑으로 즉시 편집 진입.
- 한글 붙여넣기, Tab 하위 추가, Enter 확정 후 다음 Enter 형제 추가, Shift+Enter 줄바꿈.
- 입력 중 토픽 폭/높이와 주변 트리 배치 갱신, 완료 후 문장과 줄바꿈 유지.
- 마우스로 ‘검토와 공유’를 ‘초안 작성’ 앞으로 이동해 순서 변경 확인.
- 마우스로 ‘검토와 공유’를 ‘자료 조사’ 아래로 옮기고 Cmd+Z로 부모와 순서 복원.
- Command 클릭으로 두 가지를 선택해 함께 이동. 긴 설명 하위 토픽까지 유지됨.
- 여러 가지 Cmd+C/Cmd+V로 토픽 수 5→8 확인. 실행 취소 후 한 가지 Cmd+D로 5→7 확인.
- 저장 대화상자로 work/qa/ux-review.mindmap 생성.
- 제목을 확정하지 않은 상태에서 실제 파일을 읽어 ‘자료 조사 업데이트’ 자동 저장 확인.
- Esc로 입력을 취소한 뒤 실제 파일이 원래 ‘자료 조사’로 다시 저장됨을 확인.
- Cmd+F로 긴 설명을 검색해 결과 1/1과 해당 토픽 선택 확인.
- 홈의 미리보기 카드, 별표 상태, 토픽 내용 검색 확인.
- 저장 문서 창을 닫고 홈 카드로 다시 열어 토픽 5개와 확대율 111% 복원 확인.
- 최종 빌드로 QA 앱을 다시 실행한 뒤 홈 최근 목록과 즐겨찾기 지속 확인.
- 홈의 이름 변경을 통해 ux-renamed.mindmap으로 실제 파일 이동 확인. 이전 카드 중복 없이 새 이름과 즐겨찾기 유지.
- 홈의 문서 복제가 원본 내용 5개를 가진 새 초안을 생성함을 확인.
- 긴 설명 토픽 너비를 180pt로 변경해 줄바꿈과 높이가 변하는 화면 확인.
- 기존 배포용 mindmap을 정상 종료한 뒤 `dist/mindmap.app` 최종 바이너리를 실제 실행해 새 홈 화면 확인.

### 도구 제약과 잔여 검증

외장 화면에 있던 창의 좌표 드래그는 noWindowsAvailable로 실패했다. 앱의 윈도우 메뉴로 QA 창을 내장 Retina 화면으로 옮기니 실제 드래그가 정상 동작했다.
CUA가 창 변경 직후 오래된 AX 트리를 반환하는 경우 getApp으로 다시 연결했다. 네이티브 이름 변경 필드는 setValue 뒤 실제 키 입력을 거쳐 확정했다.
한글 검증은 붙여넣기 기준이다. 실제 두벌식 IME 연속 조합, VoiceOver, 트랙패드 핀치, macOS 26 실기기/Intel,
대규모 문서 성능과 강제 종료 뒤 미저장 초안 복구는 아직 실기 검증하지 않았다.
자동 테스트와 실제 UI 검증을 구분하며, 스크린샷은 CUA 결과로 육안 확인했지만 파일로 내보내지 않았다.
아래 0.1.0 초기 기록의 드래그 미검증과 입력 중 미저장 제한은 이번 구현과 검사로 해소되었다.


## 2026-10-12 / 0.1.0

환경: macOS 27.0.1 (26A434), arm64, Swift 6.4, macOS SDK 27.0. 최소 OS 26.0.
소스는 신규 작업 폴더에 작성한 0.1.0 초기 구현이다. 소스 파일 묶음과 바이너리의 SHA-256, 캡처 상태는 assets/screenshots.json을 따른다.

### 자동 검사

- Swift 포맷 strict 검사 통과.
- Core 테스트 9개 통과: 한글/관계선 파일 왕복, 가지 삭제와 관계선 정리, 루트 보존,
  순환 부모 변경 금지, 접힘 보존과 새 하위 추가 시 펼침, 순서와 중복 관계선,
  손상 문서와 미래 버전 거부, 분리된 순환 검출, 다른 크기 61개 토픽의 겹침 없는 배치,
  150단계 깊이 제한.
- App 테스트 3개 통과: NSUndoManager로 삭제한 가지와 관계선 undo/redo, 실패한 읽기에서 기존 문서 보존,
  키보드 관계선 연결과 undo.
- Release 빌드와 codesign --verify --deep --strict 통과.
- 실행 바이너리 LC_BUILD_VERSION: minOS 26.0, SDK 27.0.

### 실제 UI

CUA로 별도 QA 앱과 직접 만든 데이터로 검사했다.
- 한글 제목 붙여넣기, Tab/Enter 하위와 형제 추가, 여러 줄 긴 설명 입력.
- 저장 대화상자로 .mindmap 파일 저장, 파일 열기로 토픽과 제목 복원.
- 관계선 키보드 연결, 설명 편집, 양쪽 화살표와 음수 곡률 설정. 파일에서 값 보존 확인.
- 가지 접기와 undo, 토픽 삭제 시 관계선 정리, undo/redo 복원.
- 긴 설명 입력 완료 후 별도 저장 명령 없이 디스크에 반영된 자동 저장 확인.
- 실제 창과 접근성 목록에서 토픽 이름, 편집기의 텍스트 입력 영역, 속성 명령 확인.

### 발견과 수정

- 편집기가 캔버스의 사용자 정의 접근성 목록에서 누락되어 편집 중 목록에 노출하도록 수정했다.
- 접근성 토픽의 비활성 상태와 잘못된 좌표를 수정해 실제 화면의 토픽 선택을 확인했다.
- 첫 창이 최소 크기로 축소되는 문제를 뷰 초기 크기 명시로 수정했다.
- 저장 패널의 AX setValue만으로는 버튼 상태가 갱신되지 않았다. 실제 입력 후 저장이 정상 동작함을 확인했다.
  문서 형식의 readable/writable type과 확장자도 명시했다.
- 문서 테스트에서 이벤트 루프 없이 undo 자동 그룹을 비활성화해 예외가 발생했다. 테스트에 명시적인 그룹을 추가했다.
- 제목 입력기의 편집 undo를 문서 구조의 undo와 분리했다.

### 미확인과 제한

- CUA 좌표 드래그는 noWindowsAvailable 오류로 완료하지 못했다. 드래그 핸들러는 구현했으며 부모 변경 규칙은 테스트했지만
  실제 포인터로 부모 이동/곡선 핸들 드래그와 트랙패드 핀치 실기 검증은 미완료다.
- 실제 한글 IME 조합, VoiceOver 읽기 순서, 대비 증가/투명도 감소의 시스템 조합은 미확인이다.
- 한글 검증은 실제 앱에 붙여넣은 텍스트를 기준으로 하며 실제 IME 타건과 구분한다.
- macOS 26 실기기와 Intel Mac, 대규모 맵 체감 성능, 비정상 종료 후 미지정 초안 복구는 미확인이다.
- 관계선은 사용자가 곡률을 조정하는 방식이며 장애물 자동 회피는 제공하지 않는다.
- 입력 중인 제목은 확정 전까지 문서 모델에 저장되지 않는다. 확정한 편집에 자동 저장을 적용한다.

### 최종 캡처 제한

마지막 재실행 검증에서 CUA의 네이티브 앱 연결이 timeoutReached로 실패했다.
프로세스 샘플은 메인 스레드가 정상 이벤트 대기 상태임을 보여 주었으며, 이 표본에서 앱의 연산 정체는 관찰되지 않았다.
다만 도구 문제라고 완전히 단정할 수는 없다. 앞선 실제 화면은 도구 결과로 검토했지만 파일로 내보내지 못했고,
최종 바이너리의 테마별 캡처도 완료하지 못했으므로 README에 없는 이미지를 연결하지 않는다.
밝은 기본 화면과 작은 창, 기본 17pt의 실제 표시는 확인했다. 어두운 테마와 최대 28pt 화면은 미확인이다.

## 2026-10-12 GitHub 소개 갱신

- 프로젝트명, 앱명과 저장소명을 mindmap으로 확정했다. 앱의 기존 표시 이름과 문서 식별자를 유지했다.
- 최신 패키징 앱을 캡처 전용 번들로 복사해 공개용 예제 문서 세 개를 열었다. 편집 화면과 새 아이콘이 적용된 홈 화면을 CUA로 촬영했다.
- docs/assets/editor.png와 home.png는 실제 창 캡처를 PNG로 변환한 파일이다. 사용자 문서는 포함하지 않았다. 상세 출처는 screenshots.json에 기록했다.
- README와 GitHub 프로필의 정적 검사 및 git diff --check를 통과했다. 소스 코드와 앱 번들은 변경하지 않아 전체 빌드와 앱 테스트는 재실행하지 않았다.
- 푸시 후 실제 GitHub README에서 아이콘 160×160과 편집/홈 이미지 로딩을 확인했다. GitHub 프로필에도 mindmap 아이콘 80×80과 소개 행이 표시된다.
- 프로필을 498px 화면에서 확인했다. Projects 표는 416px이고 가로 넘침이 없으며 mindmap 이름이 한 줄로 표시된다. 확인 후 브라우저 화면 크기를 복원했다.

## 2026-10-12 Icon Composer 아이콘

- Icon Composer에서 AppIcon.icon을 직접 열어 네 개 레이어와 두 그룹, Default 외형과 Liquid Glass 설정을 확인했다. 기존 심볼을 SVG로 옮겼다.
- actool 컴파일, 21개 테스트, 포맷 strict 검사, Release 빌드와 ad-hoc 서명 검증을 통과했다. 앱 번들의 AppIcon.icns와 Assets.car가 컴파일 결과와 일치한다.
- 사용 중인 dist/mindmap.app을 정상 종료 후 재실행했다. 앱 정보 창의 새 아이콘을 확인했고, 홈은 번들의 새 ICNS를 직접 읽도록 변경했다.
- 공개 예제 문서만 사용하는 캡처용 앱에서 홈을 재촬영했다. 편집 화면 캡처는 아이콘이 표시되지 않는 기존 화면을 유지하고 기존 촬영 출처를 개별 항목에 남겼다.
- 공개용 이미지는 Composer의 macOS Default 1024px 출력을 흰 바탕에 합성했다. 기존 외곽 투명 여백과 모서리로 표의 회색이 비치는 문제를 없앴다. 앱 네이티브 아이콘의 모서리 처리는 유지했다.
- macOS 27 실제 앱과 Default 외형을 확인했다. macOS 26 기기와 Dock의 모든 테마 조합은 별도 확인하지 않았다.
